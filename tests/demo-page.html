❓ Frequently Asked Questions

How do I operate AccessScan using only 4 keys?

Use Right and Left arrow keys to move through interactive controls. Press Down arrow to activate a button, checkbox, or text field. Press Up arrow to return or cancel.

How does text typing work without an Enter key?

When you select an editable field with Down arrow, an on-screen keyboard appears. Navigate letters using the arrow keys and press Down arrow to select each character. Then navigate to "✓ Done" to finish.

Are my login credentials kept safe?

Yes. AccessScan never logs or stores plaintext passwords. Credentials utilize browser-native PasswordCredential APIs with explicit user confirmation.
